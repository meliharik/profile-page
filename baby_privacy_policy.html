Privacy Policy

This privacy policy sets out how Melih Arik uses and protects any information that you give Melih Arik when you use this application.

Information We Collect

We may collect the following information:

  • Personal information provided by the user such as name, email address, etc.
  • Usage data collected during the use of the application, such as which features the user interacts with, duration of usage, etc.
  • Device information including device model, operating system version, etc.
  • Face data provided by the user such as uploaded images.

How We Use Collected Information

We may use the collected information for the following purposes:

  • To improve our application by analyzing the collected data.
  • To provide personalized content and features based on user preferences.
  • To ensure security and prevent misuse.
  • To generate potential future baby images using artificial intelligence based on user-provided face data.

Face Data Collection and Usage

What face data does your app collect?

Our app collects face data in the form of images uploaded by the user.

How do you use the collected face data?

The collected face data is used solely to generate potential future baby images using artificial intelligence. The face data is processed by the AI and is not stored in our database.

Will the data be shared with any third parties? Where will this information be stored?

The face data will not be shared with any third parties. It is processed by the AI and not stored on any server or database. All face data is deleted immediately after the user exits the application.

How long will face data be retained?

Face data is retained only for the duration of the user session and is deleted immediately after the user exits the application.

Changes and Updates

This privacy policy may be updated from time to time. Users will be notified of any new versions. It is the responsibility of users to regularly check this policy.
