# Müzik Dosyaları

Bu klasör music player için kullanılacak local müzik dosyalarını içerir.

## Gerekli Dosya

**`daftpunk.mp3`** - Daft Punk'ın "Around The World" şarkısı

### Dosya Ekleme:
1. `daftpunk.mp3` dosyasını bu klasöre kopyalayın
2. Dosya boyutu optimizasyonu için şarkının sadece 2-3 dakikalık kısmını kullanın
3. Player otomatik olarak 45. saniyeden başlayacak

### Desteklenen Formatlar:
- MP3 (önerilen)
- WAV
- OGG

### Not:
- Telif hakkı kurallarına dikkat edin
- Dosya boyutunu küçük tutun (max 5MB)
- Kalite: 128-192 kbps yeterli
